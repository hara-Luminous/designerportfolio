PORTFOLIO CMS PROTOTYPE
=======================

概要
----
公開ポートフォリオと管理画面を1つのHTMLにまとめたプロトタイプです。

使い方
------
1. index.html をブラウザで開く
2. 右上「管理画面」をクリック
3. 画像・作品名・カテゴリー・タグ・備考を入力
4. 「保存する」で公開サイト側に反映
5. 編集 / 削除 / ↑↓で並び替えも可能

保存方式
--------
この試作版はブラウザの localStorage に保存します。
追加画像は自動で最大1600px程度に縮小しJPEG圧縮して保存します。

重要
----
・同じブラウザ・同じ端末内でのみデータが残ります。
・複数PCで共有したり、本番公開サイトで管理画面を使う場合は
  Supabase / Firebase / WordPress 等のバックエンド接続が必要です。
・管理画面のログイン機能は本番用バックエンド実装時に追加する想定です。
